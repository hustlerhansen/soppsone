# Soppsone

Habitatkart for matsopp i Sørøst-Norge og Innlandet.

**[Åpne kartet →](https://hustlerhansen.github.io/soppsone/)**

---

Kartet viser en habitatindeks (0–100) for kantarell (*Cantharellus cibarius*)
i 1×1 km rutenett over Sørøst-Norge og Innlandet.

**BETA** — Vektene er foreløpig og ikke faglig validert av mykolog eller
naturforvalter. Scores skal ikke brukes til forvaltningsbeslutninger.

Nedbørsdata (seNorge, NVE/MET) oppdateres daglig.

### Datakilder

| Kilde | Hva den gir |
|-------|------------|
| NIBIO AR50 | Arealtype (skog / myr / åpen mark) |
| NIBIO SR16 | Treslag og bestandsalder |
| Kartverket DTM | Terrengmodell (høyde) |
| NVE/MET seNorge | 14-dagers nedbør |

Alle datakilder er åpne og offentlig tilgjengelige. Ingen API-nøkkel er nødvendig.

### Rutestørrelse og dekningsområde

1×1 km · EPSG:25833 · 19 734 celler · Sørøst-Norge og Innlandet
